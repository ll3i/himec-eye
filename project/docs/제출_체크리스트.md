### 붙임1 '공모 내용/요약' 란에 넣을 문구 (300자 이내)

> 감리·CM 현장에서 촬영하는 사진을 그대로 입력하면, AI가 안전·하자·계기 3개 축을 동시에 판독하여
> 지적사항과 근거 법규, 요구 조치사항이 채워진 검측조서 초안을 자동 생성한다. AI는 '보는 일(객체탐지)'만 하고
> 법규 판정은 결정론적 룰엔진이 담당하는 하이브리드 설계로 감리 문서의 신뢰성을 지키면서 문서 작성 부하를 줄인다.
> 공개 데이터 6,312장을 수집·재라벨링해 실제 학습·동작하는 프로토타입까지 구현하였다.

*(236자)*
