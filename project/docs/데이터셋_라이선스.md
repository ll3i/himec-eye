# 학습 데이터 출처 및 라이선스 명세

본 프로토타입은 **라이선스가 명확한 공개 데이터셋만** 사용하였으며,
각 데이터셋의 클래스를 HIMEC 검측 항목 체계로 재매핑·통합하였습니다.

## 사전학습 가중치

| 모델 | 출처 | 라이선스 |
|---|---|---|
| YOLO11n (COCO 사전학습) | Ultralytics | AGPL-3.0 |

> Ultralytics YOLO는 AGPL-3.0 라이선스입니다. 사내 시스템에 상용 적용 시에는
> Ultralytics 상용 라이선스 취득 또는 Apache-2.0 계열 대체 모델(예: RT-DETR, D-FINE) 적용을 검토해야 합니다.
> 본 프로토타입은 공모전 아이디어 검증 목적의 비상용 구현입니다.

## 재매핑 원칙

1. Roboflow-100 데이터셋의 category index 0은 supercategory 더미 클래스이므로 매핑에서 제외
2. 실무상 동일 지적사항으로 처리되는 클래스는 통합
   - `break`, `thunderbolt` → `cable_damage`
   - `Minorrotation`, `Moderaterotation`, `Severerotation` → `wall_damage`
   - `Slippage`, `corrosion` → `corrosion`
   - `Head`(맨머리) → `no_helmet`, `Face_Shield`/`Goggles` → `goggles`
3. 라벨이 하나도 없는 이미지는 배경 과다 학습 방지를 위해 제외
